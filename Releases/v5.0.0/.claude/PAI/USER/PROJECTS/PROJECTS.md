# Projects

> Canonical project index for the principal. This file is imported by `~/.claude/CLAUDE.md` at session start.

## Active Projects

Add active projects here using this format:

```markdown
### Project Name

- **Status:** active | paused | completed | archived
- **Goal:** What this project is trying to achieve
- **Current next step:** The next concrete action
- **Source of truth:** Path or URL to the project workspace
- **Notes:** Brief context the DA should remember
```

## Paused Projects

Move inactive but still relevant projects here.

## Completed Projects

Move completed projects here with a short outcome summary.

## Archive Notes

This scaffold exists so `@PAI/USER/PROJECTS/PROJECTS.md` resolves on fresh v5 installs. Keep personal project details in `PAI/USER/`, not in public release docs.
